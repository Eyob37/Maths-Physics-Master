UNIT 1

Relations and Functions

In this unit, you will revise relations and functions, study inverse relations, explore special types of functions, and learn how to combine functions using composition.

Take your time and study each subtopic one at a time.

1.1 Relations

What is a relation?

A relation is a connection between elements of two sets. In mathematics, a relation can be represented using ordered pairs.

An ordered pair: (x, y)

Any set of ordered pairs is a relation.

Example:

Let A = {1, 2, 3} and B = {4, 5, 6}.

R = {(1, 4), (2, 5), (3, 6)}

This is a relation from A to B.

Important idea

In an ordered pair (x, y), x is the first component and y is the second component.

Remember: A relation does not necessarily mean that each input has only one output.

Domain

The domain is the set of all first components of the ordered pairs in a relation.

Range

The range is the set of all second components of the ordered pairs in a relation.

For R = {(1, 3), (2, 4), (3, 5)}

Domain(R) = {1, 2, 3}
Range(R) = {3, 4, 5}
Example:

Find the domain and range of:

R = {(2, 5), (4, 7), (6, 9), (8, 7)}

Solution:

Domain = {2, 4, 6, 8}

Range = {5, 7, 9}

Repeated values are written only once when listing a set.

A relation can be represented in different ways.

1. Ordered pairs

R = {(1, 2), (2, 4), (3, 6)}

2. Mapping diagrams

Elements of one set are connected to elements of another set using arrows.

A: 1, 2, 3
B: 2, 4, 6

1 → 2
2 → 4
3 → 6

3. Tables

Values of x and y can be organized in a table.

x: 1   2   3
y: 2   4   6

4. Graphs

Ordered pairs can be plotted on the Cartesian coordinate plane.

Example:

For y = 2x, some ordered pairs are:

(1, 2), (2, 4), (3, 6).

Plotting these points gives a straight-line graph.

1.2 Inverses of Relations and Their Graphs

Meaning

The inverse of a relation is obtained by reversing the order of the components in each ordered pair.

If R = {(a, b), (c, d)}
Then R⁻¹ = {(b, a), (d, c)}
Example:

Find the inverse of:

R = {(1, 3), (2, 4), (5, 6)}

Solution:

R⁻¹ = {(3, 1), (4, 2), (6, 5)}

To find the inverse, interchange x and y in every ordered pair.

The domain and range of an inverse relation exchange their positions.

Domain(R⁻¹) = Range(R)
Range(R⁻¹) = Domain(R)
Example:

Given R = {(1, 4), (2, 5), (3, 6)}

Domain(R) = {1, 2, 3}

Range(R) = {4, 5, 6}

For the inverse:

Domain(R⁻¹) = {4, 5, 6}

Range(R⁻¹) = {1, 2, 3}

Relationship between the graphs

The graph of the inverse of a relation is the reflection of the original graph across the line y = x.

Original point: (a, b)
Inverse point: (b, a)
Example:

If a graph contains the point (2, 5), its inverse graph contains (5, 2).

The line y = x acts as the mirror line between a relation and its inverse.

1.3 Types of Functions

What is a function?

A function is a relation in which every element of the domain is related to exactly one element of the range.

Each input has exactly one output.
Example 1:

R = {(1, 2), (2, 4), (3, 6)}

This is a function because every first component has exactly one output.

Example 2:

R = {(1, 2), (1, 3), (2, 4)}

This is not a function because input 1 has two different outputs.

Function notation

y = f(x)

Here, f represents the function and x represents the input.

Example:

If f(x) = 2x + 3, find f(4).

f(4) = 2(4) + 3 = 11

Vertical line test

A graph represents a function if every vertical line intersects the graph at most once.

If a vertical line crosses a graph at more than one point, that graph does not represent a function.

Power functions

A power function is a function that can be written in the form below, where a is a constant exponent.

f(x) = xᵃ

Examples of power functions include:

f(x) = x²
g(x) = x³
h(x) = x⁴
p(x) = x⁻¹

Basic properties of power functions

The behavior of a power function depends on its exponent.

Even positive powers

f(x) = x²
  • The graph is U-shaped.
  • It is symmetric about the y-axis.
  • Its domain is all real numbers.
  • Its range is [0, ∞).

Odd positive powers

f(x) = x³
  • The graph passes through the origin.
  • It is symmetric about the origin.
  • Its domain and range are all real numbers.

Finding domain and range

Example 1:

Find the domain and range of f(x) = x².

Domain = ℝ

Range = [0, ∞)

Example 2:

Find the domain and range of f(x) = x³.

Domain = ℝ

Range = ℝ

Study the graphs and properties of different exponents carefully. The textbook discusses the basic properties of power functions in several parts.

Absolute value

The absolute value of a real number is its distance from zero on the number line.

|x| = x,   if x ≥ 0
|x| = -x,   if x < 0
Examples:

|5| = 5

|-5| = 5

|0| = 0

Properties of absolute value

|a| ≥ 0
|-a| = |a|
|ab| = |a||b|
|a/b| = |a|/|b|, b ≠ 0

Modulus function

f(x) = |x|

The graph is V-shaped and its vertex is at (0, 0).

  • Domain = ℝ
  • Range = [0, ∞)
  • The graph is symmetric about the y-axis.
Example:

Find f(-7) if f(x) = |x|.

f(-7) = |-7| = 7

Meaning

The signum function gives the sign of a real number. It tells whether the number is negative, zero, or positive.

sgn(x) = -1, if x < 0
sgn(x) = 0, if x = 0
sgn(x) = 1, if x > 0

Examples

Example 1:

sgn(-8) = -1

Example 2:

sgn(0) = 0

Example 3:

sgn(12) = 1

Domain and range

Domain = ℝ
Range = {-1, 0, 1}

Graph

The graph has a horizontal part at y = -1 for negative x, a point at (0, 0), and a horizontal part at y = 1 for positive x.

Meaning

The greatest integer function gives the greatest integer less than or equal to a given real number.

f(x) = ⌊x⌋

Examples

Example 1:

⌊3.7⌋ = 3

Example 2:

⌊5⌋ = 5

Example 3:

⌊-2.3⌋ = -3

Be careful with negative numbers. The greatest integer less than or equal to -2.3 is -3, not -2.

Domain and range

Domain = ℝ
Range = ℤ

Important interval relationship

⌊x⌋ = m if and only if m ≤ x < m + 1
Example:

Solve ⌊x⌋ = 4.

4 ≤ x < 5

Therefore, x ∈ [4, 5).

1.4 Composition of Functions

What is composition?

Composition means applying one function to the result of another function.

(f ∘ g)(x) = f(g(x))

First apply g to x. Then use the result as the input of f.

Example:

Let f(x) = 2x + 1 and g(x) = x².

Find (f ∘ g)(x).

Solution:

f(g(x)) = f(x²)

= 2(x²) + 1

= 2x² + 1

The order matters. In general, f ∘ g is not equal to g ∘ f.

Composition in both orders

(f ∘ g)(x) = f(g(x))
(g ∘ f)(x) = g(f(x))
Example:

Let f(x) = x + 3 and g(x) = 2x.

Find f ∘ g and g ∘ f.

First:

(f ∘ g)(x) = f(2x) = 2x + 3

Second:

(g ∘ f)(x) = g(x + 3) = 2(x + 3)

= 2x + 6

Notice that 2x + 3 is different from 2x + 6. Therefore, composition is not generally commutative.

Finding the domain

When finding the domain of a composition, make sure that:

  • The input belongs to the domain of the inside function.
  • The output of the inside function belongs to the domain of the outside function.
Example:

Let f(x) = √x and g(x) = x - 2.

Find (f ∘ g)(x) and its domain.

Solution:

f(g(x)) = √(x - 2)

For a real square root:

x - 2 ≥ 0

x ≥ 2

Domain = [2, ∞).

Identity function

An identity function maps every element to itself.

I(x) = x

Inverse function

The inverse function reverses the operation of the original function. It is denoted by f⁻¹(x).

f(f⁻¹(x)) = x
f⁻¹(f(x)) = x
Example:

Find the inverse of f(x) = 2x + 4.

Step 1: Write y = 2x + 4.

Step 2: Interchange x and y.

x = 2y + 4

Step 3: Solve for y.

x - 4 = 2y

y = (x - 4)/2

Answer:

f⁻¹(x) = (x - 4)/2

Graph of inverse functions

The graph of an inverse function is the reflection of the original function across the line y = x.

A function must be one-to-one on its domain to have an inverse that is also a function.
