1.1 Relations

Learn about patterns, coordinate systems, relations, domain, range and graphs.

What is a pattern?

A pattern is a regularity in numbers, designs or ideas. Its elements follow a predictable rule.

1. Arithmetic pattern

An arithmetic pattern is formed by adding or subtracting the same number to obtain the next term.

Example:

2, 4, 6, 8, 10, ...

The rule is to add 2 to the previous term.

The next terms are 12 and 14.

2. Geometric pattern

A geometric pattern is formed by multiplying or dividing each term by the same number.

Example:

2, 4, 8, 16, 32, ...

The rule is to multiply each term by 2.

The next term is 64.

Remember: Arithmetic patterns use addition or subtraction. Geometric patterns use multiplication or division.

What is a Cartesian coordinate system?

It is a system used to locate points on a plane using two perpendicular number lines called the x-axis and y-axis.

  • x-axis: The horizontal axis.
  • y-axis: The vertical axis.
  • Origin: The point where the axes meet, (0, 0).
  • Abscissa: The first coordinate (x).
  • Ordinate: The second coordinate (y).
A point is written as (x, y).

The four quadrants

  • Quadrant I: (+, +)
  • Quadrant II: (-, +)
  • Quadrant III: (-, -)
  • Quadrant IV: (+, -)
Example:

Consider point P(3, 2).

Move 3 units to the right and 2 units upward from the origin.

Therefore, P is in Quadrant I.

The order of coordinates is important. (2, 3) and (3, 2) represent different points.

What is a relation?

A relation is a set of ordered pairs that shows a relationship between elements.

R = {(x, y) : x and y satisfy a given condition}

Ordered pairs

An ordered pair consists of two elements written as (x, y). The first element is the first component, and the second is the second component.

Example:

R = {(1, 2), (2, 4), (3, 6)}

Each pair shows that the second number is twice the first.

Domain of a relation

The domain is the set of all first components of the ordered pairs in a relation.

Range of a relation

The range is the set of all second components of the ordered pairs in a relation.

Example:

R = {(-2, 1), (-1, 0), (0, 0), (4, 2), (3, 5)}

Domain = {-2, -1, 0, 3, 4}

Range = {0, 1, 2, 5}

Repeated values are written only once when describing a domain or range as a set.

What is a graph of a relation?

A graph of a relation is a visual representation of its ordered pairs on a Cartesian coordinate plane.

How to draw a relation

  1. Identify the ordered pairs.
  2. Draw the x-axis and y-axis.
  3. Choose a suitable scale.
  4. Locate each ordered pair.
  5. Draw the required graph according to the relation.
Example:

R = {(1, 2), (2, 4), (3, 6)}

Plot the three points on the coordinate plane.

They lie on the straight line y = 2x.

Graphs of quadratic relations

Some relations have curved graphs. A common example is a parabola, which is the graph of a quadratic function.

y = ax² + bx + c, where a ≠ 0

The graph of a quadratic function has a vertex and an axis of symmetry.

1.2 Functions

Understand functions, their properties, types and combinations.

What is a function?

A function is a special type of relation in which every input is associated with exactly one output.

y = f(x)

Here, x represents the input and f(x) represents the output.

Example 1: Function

R = {(1, 2), (2, 4), (3, 6)}

Every input has exactly one output. Therefore, it is a function.

Example 2: Not a function

R = {(1, 2), (1, 3), (2, 4)}

The input 1 has two different outputs, 2 and 3. Therefore, it is not a function.

Domain and range of a function

  • Domain: The set of all allowed input values.
  • Range: The set of all resulting output values.
Example:

Let f(x) = 2x + 1 and domain = {1, 2, 3}.

f(1) = 2(1) + 1 = 3

f(2) = 2(2) + 1 = 5

f(3) = 2(3) + 1 = 7

Range = {3, 5, 7}

Vertical Line Test

The vertical line test is used to determine whether a graph represents a function.

  • If every vertical line intersects the graph at most once, it is a function.
  • If any vertical line intersects the graph more than once, it is not a function.

Types of functions covered in the textbook

1. Constant function

f(x) = b

The output remains the same for every input. Its graph is a horizontal line.

Example: f(x) = 3

2. Linear function

f(x) = ax + b

Its graph is a straight line. The value of a determines whether the graph increases or decreases.

  • If a > 0, the function is increasing.
  • If a < 0, the function is decreasing.
  • If a = 0, the function is constant.
Example: f(x) = 2x + 1

Slope and intercept

In the linear function f(x) = ax + b:

  • a is the slope.
  • b is the y-intercept.
Slope = (y₂ - y₁) / (x₂ - x₁)

3. Quadratic function

f(x) = ax² + bx + c, a ≠ 0

Its graph is a parabola. The graph opens upward when a is positive and downward when a is negative.

Important quadratic graph terms

  • Vertex: The turning point of the parabola.
  • Axis of symmetry: The vertical line passing through the vertex.
  • x-intercept: Where the graph crosses the x-axis.
  • y-intercept: Where the graph crosses the y-axis.
  • Leading coefficient: The coefficient of x².
For f(x) = a(x - h)² + k, the vertex is (h, k).

What is a combination of functions?

A combination of functions means creating a new function by performing operations on two or more functions.

Let f and g be two functions.

1. Addition

(f + g)(x) = f(x) + g(x)

2. Subtraction

(f - g)(x) = f(x) - g(x)

3. Multiplication

(fg)(x) = f(x) × g(x)

4. Division

(f/g)(x) = f(x) / g(x), where g(x) ≠ 0
Worked Example:

Let f(x) = x + 2 and g(x) = 3x.

Addition:

(f + g)(x) = (x + 2) + 3x = 4x + 2

Subtraction:

(f - g)(x) = (x + 2) - 3x = 2 - 2x

Multiplication:

(fg)(x) = (x + 2)(3x) = 3x² + 6x

Division:

(f/g)(x) = (x + 2)/(3x), x ≠ 0

Domain of combination of functions

The domain of the sum, difference and product is the common domain of the two functions.

For division, the denominator must also be nonzero.

Always check the domain before performing operations on functions.

1.3 Applications of Relations and Functions

Apply relations and functions to practical problems and quadratic graphs.

Using mathematical relationships

Relations and functions can describe how one quantity depends on another quantity.

Example 1: Estimating height

Suppose a relationship between femur length x (in cm) and height y (in cm) is:

y = 2.47x + 54

Find the estimated height when x = 44.

y = 2.47(44) + 54

y = 108.68 + 54

y = 162.68 cm

Example 2: Area and perimeter

Suppose the area of a square is (x + 9)². Find its perimeter when x = 10.

Side length = x + 9

Side length = 10 + 9 = 19

Perimeter = 4 × 19

Perimeter = 76 units

Maximum and minimum values

A quadratic function has a turning point called its vertex. Depending on the direction of the parabola, the vertex represents either a minimum or a maximum value.

When the parabola opens upward

If a is positive, the graph opens upward. Its vertex gives the minimum value.

When the parabola opens downward

If a is negative, the graph opens downward. Its vertex gives the maximum value.

f(x) = a(x - h)² + k
Vertex = (h, k)
Example:

Find the maximum value of:

f(x) = -x² + 6x - 8

Complete the square:

f(x) = -(x² - 6x) - 8

f(x) = -(x² - 6x + 9) + 9 - 8

f(x) = -(x - 3)² + 1

Vertex = (3, 1)

Maximum value = 1

Completing the square helps us identify the vertex and determine the maximum or minimum value.

What is a graphical solution?

A quadratic equation can be solved by drawing the graph of its corresponding quadratic function and identifying where it intersects the x-axis.

Steps

  1. Rearrange the equation so one side is equal to zero.
  2. Write the corresponding quadratic function.
  3. Draw its graph.
  4. Find where the graph crosses or touches the x-axis.
  5. Read the x-coordinates. These are the solutions.
Example:

Solve x² - 4 = 0 graphically.

Consider y = x² - 4.

Set y = 0:

x² - 4 = 0

(x - 2)(x + 2) = 0

x = -2 or x = 2

The graph intersects the x-axis at (-2, 0) and (2, 0).

The x-intercepts of the graph give the real solutions of the corresponding quadratic equation.

What is a quadratic inequality?

A quadratic inequality compares a quadratic expression with zero using inequality symbols.

ax² + bx + c > 0
ax² + bx + c < 0
ax² + bx + c ≥ 0
ax² + bx + c ≤ 0

Graphical method

  1. Draw the graph of the corresponding quadratic function.
  2. Identify its x-intercepts.
  3. Observe where the graph is above the x-axis.
  4. Observe where the graph is below the x-axis.
  5. Select the intervals that satisfy the inequality.
Example:

Solve x² - 4 > 0.

Consider y = x² - 4.

The x-intercepts are -2 and 2.

The parabola opens upward.

It is above the x-axis when x < -2 or x > 2.

Solution: (-∞, -2) ∪ (2, ∞)

For strict inequalities (> or <), the roots are not included. For inequalities with equality (≥ or ≤), the roots are included.
