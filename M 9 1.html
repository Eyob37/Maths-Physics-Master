1.1 Sets and Elements

Understanding sets and their elements.

What is a Set?

A set is a collection of well-defined objects or elements.

A set is well-defined when we can clearly determine whether a particular object belongs to the set or not.

Examples of Sets

Example 1: Well-defined set

The collection of all students in your class.

This is well-defined because we can identify exactly who belongs to the class.

Example 2: Not well-defined

The collection of beautiful girls in your class.

This is not well-defined because beauty is subjective. Different people may have different opinions.

Representation of Sets

Sets are usually represented by capital letters:

A, B, C, X, Y, Z

Elements are usually represented by small letters:

a, b, c, x, y, z

Example:

A = {1, 2, 3, 4, 5}

Here, A is the set and 1, 2, 3, 4 and 5 are its elements.

Membership Symbols

∈

Belongs to a set.

2 ∈ A

∉

Does not belong to a set.

8 ∉ A

Worked Example

Suppose A is the set of positive even numbers.

A = {2, 4, 6, 8, 10, ...}

Determine whether the following elements belong to A.

  • 4 ∈ A
  • 5 ∉ A
  • -2 ∉ A
  • 0 ∉ A

Check Your Understanding

Let A = {1, 2, 3, 4, 5, 6}.

Does 5 belong to A?

Does 8 belong to A?

1.2 Set Description

Different methods of describing sets.

Introduction

Sets can be described in different ways. The textbook discusses verbal description and listing methods.

1. Verbal Method (Statement Form)

In this method, the elements of a set are described using ordinary English words.

Example

The set of whole numbers greater than 1 and less than 6.

A = {whole numbers greater than 1 and less than 6}

2. Listing Methods

There are two listing methods:

2.1 Complete Listing Method (Roster Method)

All elements of the set are listed, separated by commas and enclosed within braces { }.

Example 1

Set of positive even integers less than 7.

A = {2, 4, 6}

Example 2

Set of vowels in the English alphabet.

V = {a, e, i, o, u}

2.2 Partial Listing Method

This method is used when listing every element is difficult or impossible. A few elements and dots (...) are used to represent the remaining elements.

Example 1

Natural numbers:

A = {1, 2, 3, 4, ...}

Example 2

Positive even numbers:

B = {2, 4, 6, 8, ...}

Compare the Methods

Verbal

Describes elements using words.

Example: Natural numbers less than 5.

Complete Listing

Lists every element.

Example: {1, 2, 3, 4}

Partial Listing

Lists some elements and uses dots.

Example: {1, 2, 3, ...}

Practice

Which method is used in the following?

A = {2, 4, 6, 8, ...}




1.3 The Notion of Sets

Important types and relationships of sets.

1. Empty Set

A set that does not contain any element is called an empty set, void set or null set.
∅ or { }

Example

Let:
A = {x ∈ ℕ | 1 < x < 2}
There is no natural number between 1 and 2. Therefore:
A = ∅

2. Finite and Infinite Sets

A finite set contains a definite number of elements. An infinite set does not have a finite number of elements.

Finite Set

{1, 2, 3, 4, 5}

It has five elements.

Infinite Set

{1, 2, 3, ...}

It continues without end.

The number of elements of A is represented by n(A).

If A = {1, 2, 3, 4}, then n(A) = 4

3. Equal Sets

Two sets A and B are equal if and only if they contain exactly the same elements.
A = B

Example

A = {1, 2, 3, 4}
B = {4, 3, 2, 1}

Therefore, A = B.

Remember: The order of elements does not matter.

4. Equivalent Sets

Two sets are equivalent if there is a one-to-one correspondence between their elements.
n(A) = n(B)
A = {1, 2, 3}
B = {Red, Blue, Green}

Both sets contain three elements.

Therefore, A and B are equivalent.

5. Universal Set

A universal set, usually denoted by U, contains all elements of the related sets under discussion.
U = {1, 2, 3, 4, 5, 6}

For example, if A = {2, 4, 6} and B = {1, 3, 5}, then U contains all elements of A and B.

6. Subset

A set A is a subset of B if every element of A is also an element of B.
A ⊆ B
A = {1, 2}
B = {1, 2, 3, 4}

Every element of A belongs to B.

Therefore, A ⊆ B.

7. Proper Subset

A is a proper subset of B if every element of A belongs to B and B contains at least one additional element.
A ⊂ B
A = {1, 2}
B = {1, 2, 3}

Therefore, A is a proper subset of B.

Important distinction: Equal sets have exactly the same elements. Equivalent sets have the same number of elements (for finite sets), even if their elements differ.

Practice Question

A = {1, 2, 3} and B = {3, 2, 1}.

Which statement is correct?




1.4 Operations on Sets

Creating new sets using mathematical operations.

Introduction

Set operations are processes used to form new sets from existing sets.

The textbook discusses:

  • Union
  • Intersection
  • Complement
  • Difference
  • Symmetric Difference
  • Cartesian Product

Venn Diagrams

A Venn diagram is a schematic or pictorial representation of sets involved in a discussion.

Sets are usually represented by circles enclosed in a rectangle representing the universal set.

1. Union (∪)

The union of two sets A and B is the set of all elements that belong to A or B or both.
A ∪ B

Example

A = {1, 2, 3}
B = {3, 4, 5}
A ∪ B = {1, 2, 3, 4, 5}

2. Intersection (∩)

The intersection of A and B is the set of elements that belong to both sets.
A ∩ B

Example

A = {1, 2, 3}
B = {3, 4, 5}
A ∩ B = {3}
Two sets are disjoint if their intersection is empty. That is A ∩ B = ∅.

3. Complement (′)

The complement of A is the set of all elements of the universal set U that are not in A.
A′ = U − A

Example

U = {0, 1, 2, 3, 4}
A = {3, 4}
A′ = {0, 1, 2}

4. Difference (−)

The difference A − B contains all elements that belong to A but do not belong to B.
A − B = {x | x ∈ A and x ∉ B}

Example

A = {0, 1, 2, 3, 4}
B = {3, 4}
A − B = {0, 1, 2}
B − A = ∅

5. De Morgan's Laws

There are two important statements:

(A ∪ B)′ = A′ ∩ B′
(A ∩ B)′ = A′ ∪ B′

6. Symmetric Difference (∆)

The symmetric difference contains elements that belong to A or B but not to both.
A ∆ B = (A − B) ∪ (B − A)

Example

A = {1, 2, 4, 5}
B = {2, 3, 5, 7}

A − B = {1, 4}

B − A = {3, 7}

A ∆ B = {1, 3, 4, 7}

7. Cartesian Product (×)

The Cartesian product of A and B is the set of all ordered pairs (a, b), where a belongs to A and b belongs to B.
A × B = {(a,b) | a ∈ A and b ∈ B}

Example

A = {1, 2}
B = {a, b}
A × B = {(1,a), (1,b), (2,a), (2,b)}
n(A × B) = n(A) × n(B)

1.5 Application

Number of elements in the union of two sets.

Number of Elements of a Union

When two sets have common elements, we must avoid counting those elements twice.

n(A ∪ B) = n(A) + n(B) − n(A ∩ B)

Where:

  • n(A) = number of elements in A.
  • n(B) = number of elements in B.
  • n(A ∩ B) = number of common elements.
  • n(A ∪ B) = number of elements in the union.

Special Case: Disjoint Sets

If A and B have no common elements, their intersection is empty.

A ∩ B = ∅
n(A ∪ B) = n(A) + n(B)

Worked Example

Suppose:

  • n(A) = 20
  • n(B) = 28
  • n(A ∪ B) = 36

Find n(A ∩ B).

Solution:

Using the formula:

n(A ∪ B) = n(A) + n(B) − n(A ∩ B)

Substitute the given values:

36 = 20 + 28 − n(A ∩ B)

Therefore:

n(A ∩ B) = 48 − 36 = 12
Answer: 12

Real-life Application

Suppose 60 students are in a classroom. 35 students like Mathematics, 30 like Physics, and 15 like both subjects.

How many students like at least one subject?

n(M ∪ P) = 35 + 30 − 15
n(M ∪ P) = 50

Therefore, 50 students like at least one subject.

Practice Question

If n(A) = 34, n(B) = 46 and n(A ∪ B) = 70, find n(A ∩ B).
